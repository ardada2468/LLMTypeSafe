# Support

- **Questions and how-tos** — start with the [README](README.md), the
  [docs site](https://ardada2468.github.io/LLMTypeSafe/) and the runnable
  [examples](examples). If the answer is not there, open a
  [question issue](https://github.com/ardada2468/LLMTypeSafe/issues/new/choose).
- **Bugs** — open a [bug report](https://github.com/ardada2468/LLMTypeSafe/issues/new/choose)
  with a minimal reproduction. `MockLM` from `@ts-dspy/core/testing` makes a
  reproduction that needs no API key.
- **Security problems** — do not open an issue; see [SECURITY.md](SECURITY.md).
- **Upgrading** — see [MIGRATION.md](MIGRATION.md).

## Compatibility

- Node.js 22 or newer; every release is tested on Node 22, 24 and 26.
- ESM and CommonJS builds, with type declarations for both.
- The packages follow semantic versioning. While the version is below 1.0, a
  minor release may contain breaking changes; each one is listed in the
  changelog and in MIGRATION.md.
