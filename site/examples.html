Example 1

Predictstring signature

Question answering

The shortest useful program. A string signature needs no decorators.

import { Predict, configure } from '@ts-dspy/core'
import { AnthropicLM } from '@ts-dspy/anthropic'

configure({ lm: new AnthropicLM({ apiKey: process.env.ANTHROPIC_API_KEY! }) })

const qa = new Predict('question -> answer')
const out = await qa.forward({ question: 'What is a B-tree used for?' })

console.log(out.answer)

Output

B-trees keep sorted data on disk with a high branching factor, so a
lookup touches few blocks. Databases and filesystems use them for indexes.

Example 2

Predictnumberboolean

Classification with a confidence score

Declaring type: 'number' is what makes confidence arithmetic-safe. Without it you get a string that looks like a number until you multiply by it. 

import { Signature, InputField, OutputField, Predict } from '@ts-dspy/core'

class TriageTicket extends Signature {
  static description = 'Classify a support ticket.'

  @InputField({ description: 'the ticket body' })
  ticket!: string

  @OutputField({ description: 'one of: billing, bug, feature, other' })
  category!: string

  @OutputField({ description: 'confidence from 0 to 1', type: 'number' })
  confidence!: number

  @OutputField({ description: 'true if a human should see this today', type: 'boolean' })
  urgent!: boolean
}

const out = await new Predict(TriageTicket).forward({
  ticket: 'Charged twice this month and support never replied.',
})

if (out.urgent && out.confidence > 0.7) page(out.category)

Output

{ category: 'billing', confidence: 0.93, urgent: true }
         string              number          boolean

Example 3

Predictstring[]optional

Structured extraction

Arrays and optional fields. required: false makes a field optional in both the schema and the inferred type, so a missing value is not a failure. 

class ExtractInvoice extends Signature {
  static description = 'Pull structured fields out of an invoice email.'

  @InputField({ description: 'raw email text' })
  email!: string

  @OutputField({ description: 'vendor name' })
  vendor!: string

  @OutputField({ description: 'total in dollars', type: 'number' })
  total!: number

  @OutputField({ description: 'each line item description', type: 'string[]' })
  lineItems!: string[]

  @OutputField({ description: 'due date if stated', required: false })
  dueDate?: string
}

const out = await new Predict(ExtractInvoice).forward({ email })

Output — note "$1,240.00" coerced to a number

{
  vendor: 'Northwind Traders',
  total: 1240,
  lineItems: [ 'Annual licence', 'Priority support' ],
  dueDate: undefined
}

Example 4

ChainOfThought2 calls

Chain of thought

Reasons first, answers second. You get the reasoning alongside the validated fields, which is useful to log even when you do not show it. 

import { ChainOfThought } from '@ts-dspy/core'

class SolveWordProblem extends Signature {
  @InputField({ description: 'a word problem' })
  problem!: string

  @OutputField({ description: 'the numeric answer', type: 'number' })
  answer!: number
}

const out = await new ChainOfThought(SolveWordProblem).forward({
  problem: 'A train leaves at 09:40 and arrives at 13:15. How many minutes?',
})

logger.debug({ reasoning: out.reasoning })
console.log(out.answer)  // 215, as a number

Example 5

ReActtoolstrajectory

A ReAct agent

The model decides which tool to call and when it has enough — then an extract step writes the answer from everything it gathered. Tool descriptions are the whole interface: write them as instructions, and say what the input should be. 

import { ReAct } from '@ts-dspy/core'

const support = new ReAct('question -> answer', {
  tools: {
    orderStatus: {
      description: 'Look up an order. Input: the order ID, e.g. A-4182.',
      function: async (id) => JSON.stringify(await orders.find(id.trim())),
    },
    shippingPolicy: {
      description: 'Return the shipping policy. Input: ignored.',
      function: () => policies.shipping,
    },
  },
  maxSteps: 8,
  onEvent: (e) => logger.debug({ react: e }),
})

const out = await support.forward({
  question: 'Order A-4182 has not arrived. Is it late?',
})

console.log(out.answer, 'in', out.steps, 'steps')
console.log(out.trajectory)

out.trajectory, then the extract step

thought_0:      Need the order's ship date before judging lateness.
tool_name_0:    orderStatus
tool_args_0:    {"input":"A-4182"}
observation_0:  {"shipped":"2026-08-14","carrier":"DHL","eta":"2026-08-18"}
thought_1:      ETA has passed. Check the policy for what counts as late.
tool_name_1:    shippingPolicy
tool_args_1:    {"input":""}
observation_1:  Orders are late 2 business days past ETA.
thought_2:      I have what I need.
tool_name_2:    finish

extract  reasoning: ETA was 18 Aug; it is now 3 business days past it.
         answer:    Yes - it is three days past the 18 Aug ETA.
Out of steps

If maxSteps runs out before the agent calls finish, it does not throw: the extract step answers from the trajectory it has, and steps equals maxSteps.

Example 6

streamingno validation

Streaming to a UI

A provider stream is raw tokens and skips signature validation: there is no complete reply to check yet. For fields that fill in and are validated at the end, use predict.stream() or streamify instead. 

const lm = new AnthropicLM({ apiKey: process.env.ANTHROPIC_API_KEY! })

for await (const chunk of lm.generateStream('Explain WAL in two paragraphs.')) {
  res.write(chunk.content)
  if (chunk.done) logger.info({ usage: chunk.usage })
}
res.end()

Example 7

portability3 providers

Swapping providers

Signatures and modules name no vendor, so the provider is a runtime choice. This is also how you run the same evaluation across models. 

import { AnthropicLM } from '@ts-dspy/anthropic'
import { OpenAILM } from '@ts-dspy/openai'
import { GeminiLM } from '@ts-dspy/gemini'

const providers = {
  claude: () => new AnthropicLM({ apiKey: process.env.ANTHROPIC_API_KEY! }),
  gpt:    () => new OpenAILM({ apiKey: process.env.OPENAI_API_KEY! }),
  gemini: () => new GeminiLM({ apiKey: process.env.GEMINI_API_KEY! }),
}

for (const [name, make] of Object.entries(providers)) {
  const triage = new Predict(TriageTicket, make())
  const out = await triage.forward({ ticket })
  console.log(name, out.category, out.confidence)
}

Example 8

ValidationErrorLMErrorproduction

Handling failure

The case worth writing code for. A validation failure tells you which field the model got wrong and what it actually said, which is usually enough to fix the field description. 

import { ValidationError, LMError } from '@ts-dspy/core'

async function triageWithFallback(ticket: string) {
  try {
    return await triage.forward({ ticket }, { timeout: 20_000 })
  } catch (err) {
    if (err instanceof ValidationError) {
      // The model answered, but not in the declared shape.
      logger.warn({
        fields: err.issues.map((i) => i.field),
        raw: err.rawOutput,
      })
      return { category: 'other', confidence: 0, urgent: true }
    }

    if (err instanceof LMError) {
      // The call itself failed. The SDK already retried.
      logger.error({ cause: err.cause })
      throw err
    }

    throw err
  }
}

A caught ValidationError

ValidationError: Output did not match TriageTicket

  issues:    [ { field: 'confidence',
                 expected: 'number',
                 received: 'very high' } ]
  rawOutput: 'category: billing\nconfidence: very high\nurgent: yes'
Reading this

urgent: yes passed — "yes" is accepted for a boolean. "very high" is not a number and no amount of coercion makes it one, so the whole reply is rejected rather than handing back a partly-wrong object. Tightening the description to 'confidence from 0 to 1' is the fix.

Example 9

vitestno network

Testing without a network

Pass a stub model and your tests are deterministic, free, and fast. Test the shapes you fear, not the one you hope for. 

import { describe, it, expect } from 'vitest'
import { Predict, ValidationError } from '@ts-dspy/core'
import { MockLM } from '@ts-dspy/core/testing'

describe('TriageTicket', () => {
  it('coerces a numeric string', async () => {
    const lm = new MockLM({ responses: ['category: bug\nconfidence: 0.82\nurgent: yes'] })
    const out = await new Predict(TriageTicket, lm).forward({ ticket: 'x' })

    expect(out.confidence).toBe(0.82)
    expect(typeof out.confidence).toBe('number')
    expect(out.urgent).toBe(true)
  })

  it('rejects prose where a number was declared', async () => {
    const lm = new MockLM({ responses: ['category: bug\nconfidence: very high\nurgent: yes'] })

    await expect(new Predict(TriageTicket, lm).forward({ ticket: 'x' }))
      .rejects.toBeInstanceOf(ValidationError)
  })
})

Example 10

Modulesave / load

Composing a program and saving it

A program is a Module holding other modules. Its learned state — every predictor's demos and instructions — saves to JSON and loads into a fresh instance of the same shape. 

import { Module, Predict, ChainOfThought, type LLMCallOptions } from '@ts-dspy/core'

class Pipeline extends Module {
  classify = new Predict('ticket -> team')
  reply = new ChainOfThought('ticket, team -> reply')

  async forward(inputs: { ticket: string }, options?: LLMCallOptions) {
    const { team } = await this.classify.forward(inputs, options)
    return this.reply.forward({ ...inputs, team }, options)
  }
}

const program = new Pipeline()
program.namedPredictors().map(([path]) => path)  // ['classify', 'reply']
await program.save('pipeline.json')
const restored = await new Pipeline().load('pipeline.json')
npm run example:save-load   # examples/composition-save-load.ts

Example 11

RetrieveKNNFewShotembeddings

Retrieval with nearest-neighbour demos

InMemoryVectorStore indexes passages with an embedder; the same embedder lets KNNFewShot pick, per call, the training examples most like the question as demos. 

import { InMemoryVectorStore, Retrieve, KNNFewShot, ChainOfThought } from '@ts-dspy/core'
import { OpenAIEmbedder } from '@ts-dspy/openai'

const embedder = new OpenAIEmbedder()
const store = new InMemoryVectorStore(embedder)
await store.addAll(handbook)

const { passages } = await new Retrieve({ k: 3, retriever: store }).forward({ query: question })

const answer = new KNNFewShot({ k: 2, embedder, trainset })
  .compile(new ChainOfThought('context, question -> answer'))

await answer.forward({ context: passages.map((p) => p.text).join('\n'), question })
npm run example:rag   # examples/rag-knn.ts

Example 12

MIPROv2optimizer

Optimizing instructions and demos with MIPROv2

MIPROv2 proposes instructions grounded in your data, bootstraps demo sets, and searches the combinations with a seeded TPE sampler. The student is left untouched; the compiled copy saves like any program. 

import { MIPROv2, exactMatch } from '@ts-dspy/core'

const compiled = await new MIPROv2({ metric: exactMatch, auto: 'light', seed: 7 })
  .compile(new Predict(RouteTicket), { trainset, valset })

console.log(compiled.miproResults.bestScore)
npm run example:mipro   # examples/mipro.ts

Example 13

GEPAmetric feedback

Reflective optimization with GEPA

GEPA reads what your metric says about a run, not just its score, and has a reflection model rewrite the instructions. Return { score, feedback }. 

import { GEPA, type Metric } from '@ts-dspy/core'

const metric: Metric = (example, prediction) =>
  prediction.get('team') === example.get('team')
    ? { score: 1, feedback: 'Correct.' }
    : { score: 0, feedback: `Should be ${example.get('team')}: billing covers charges and invoices.` }

const compiled = await new GEPA({ metric, reflectionLM: strongLM, maxMetricCalls: 150 })
  .compile(new Predict(RouteTicket), { trainset, valset })

compiled.detailedResults.bestIndex
npm run example:gepa   # examples/gepa.ts

Example 14

@ts-dspy/mcpReAct

An agent over MCP tools

Connect to any Model Context Protocol server and hand its tools to ReAct. Tool errors reach the model as observations it can act on. 

import { ReAct } from '@ts-dspy/core'
import { connectMcp, mcpTools } from '@ts-dspy/mcp'

const client = await connectMcp({ command: 'npx', args: ['-y', '@modelcontextprotocol/server-filesystem', '.'] })
try {
  const agent = new ReAct('question -> answer', { tools: await mcpTools(client) })
  console.log((await agent.forward({ question: 'Which example files exist?' })).answer)
} finally {
  await client.close()
}
npm run example:mcp   # examples/mcp-react.ts

Example 15

@ts-dspy/oteltracing

OpenTelemetry spans

Register a tracer provider, call instrument(), and every module, LM call and tool call becomes a span, nested as the calls were. 

import { trace } from '@opentelemetry/api'
import { BasicTracerProvider, ConsoleSpanExporter, SimpleSpanProcessor } from '@opentelemetry/sdk-trace-base'
import { instrument } from '@ts-dspy/otel'

trace.setGlobalTracerProvider(
  new BasicTracerProvider({ spanProcessors: [new SimpleSpanProcessor(new ConsoleSpanExporter())] })
)
instrument()

await new ChainOfThought('question -> answer').forward({ question })
// ts-dspy.module ChainOfThought  →  chat gpt-5.2
npm run example:otel   # examples/otel-tracing.ts

Example 17

RefineBestOfN

Retrying until a reward is met

Refine re-runs a program until a reward function is satisfied, and between attempts asks a model what went wrong — advice the next attempt receives as a hint. 

import { Refine, ChainOfThought } from '@ts-dspy/core'

const tweet = new Refine(new ChainOfThought('topic -> tweet'), {
  n: 3,
  rewardFn: (inputs, prediction) => (prediction.tweet.length <= 280 ? 1 : 0),
  threshold: 1,
})

const { tweet: text } = await tweet.forward({ topic: 'write-ahead logging' })
npm run example:refine   # examples/refine.ts

Example 18

streamifystreaming

Streaming a whole program

streamify turns any program into an async stream of status messages, field deltas from every predictor, and the final prediction. 

import { streamify } from '@ts-dspy/core'

for await (const event of streamify(program)({ ticket })) {
  if (event.type === 'status') console.log(`[${event.message}]`)
  else if (event.type === 'field') process.stdout.write(event.delta ?? '')
  else console.log('\n', event.prediction.toObject())
}
npm run example:streamify   # examples/streamify.ts
